Student Grade Calculator:

This project takes 5 input: student's name, roll no, and 3 static subject marks
and gives Student's Name, Roll No, Total Obtained Marks, Percentage, Grade and also Status (Pass/Fail) in the output <br>

Features:

Total Obtained Marks<br>
Percentage with 2 decimal points<br>
Grade<br>
Status<br>
Set Dynamic value of class (depends on status Pass/Fail)<br>

Logic:<br>

select all input elements at once then store every input's value in individual variables<br>
calculate total marks and percentage till 2 decimal points<br>

grade, status and color of status content depends on percentage<br>
so calculate these by if else<br>

set Dynamic Value of class for "statusClass" to change the color of status content acc to status (pass/fail)
