Student Grade Calculator:

This project takes 5 input: student's name, roll no, and 3 static subject marks
and gives Student's Name, Roll No, Total Obtained Marks, Percentage, Grade and also Status (Pass/Fail) in the output

Features:

Total Obtained Marks
Percentage with 2 decimal points
Grade
Status
Set Dynamic value of class (depends on status Pass/Fail)

Logic:

select all input elements at once then store every input's value in individual variables
calculate total marks and percentage till 2 decimal points

grade, status and color of status content depends on percentage
so calculate these by if else

set Dynamic Value of class for "statusClass" to change the color of status content acc to status (pass/fail)

Includes in SMIT Assignment
